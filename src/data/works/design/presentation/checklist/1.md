**Перед тем как прикрепить ссылку на свою работу мы рекомендуем проверить себя по чек-листу:**

-  Создана одна презентация формата 1920*1080px в PDF для Нейромаркетингового Агентства «Neurovision agency»
- Проведена аналитическая подготовительная работа, аргументация прописана отдельно (смотри конспект 1. Аналитика)
- В презентации нет лишних артефактов, пустых слайдов, удалены черновики или перенесены на отдельный слайд
- В презентации есть все составляющие проекта: описание задачи, есть референсы, определена ЦА, описаны идеи, подобрана цветовая палитра, шрифт
- Для всего проекта подобрана шрифтовая пара (смотри конспект 7. Основы типографики)
- Для всего проекта подобрана цветовая гамма (смотри конспект 5. Цвет)
- Проработана инфографика / иконки / графики / диаграммы / иллюстрации, которые визуализируют и упрощают сложные тезисы
- По желанию подобраны фотографии
- В презентации есть объединяющие стилизующие элементы, постоянные и переменные константы
- Ссылка на презентацию размещена в любом облаке и работает корректно.
