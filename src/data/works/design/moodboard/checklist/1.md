Проверь себя перед завершением проекта:
- В проекте есть описание портрета целевой аудитории
- Создано ассоциативное поле
- Созданы слайды с функциональными и стилистическими референсами, изображения хорошего качества
- Есть слайд с описанием идеи для проекта, есть эскизы
- У проекта есть обложка и заключительный слайд
