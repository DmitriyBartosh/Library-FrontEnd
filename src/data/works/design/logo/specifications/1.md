**Твоя задача:** создать шрифтовой логотип для кафе «Аист», который находится в Сочи. Кафе только открывается и пока выделен бюджет только на логотип, чтобы сделать вывеску на вход. В кафе шикарный интерьер в мятно-розовых тонах с уютными деталями. Заказчику хотелось бы увидеть именно такие цветовые решения в логотипе. Здесь есть ароматный кофе, полезные завтраки, натуральные сладости, приготовленные по домашним рецептам. Для маленьких гостей кафе собирает вкусные ланчбоксы с чистым составом. Заказчик хочет увидеть такие идеи логотипа, которые бы отражали основные ценности их кафе: уют, семья, эстетика в каждой детали. Самое главное — уйти от декоративности. Нужны только буквы, без знака. Клиент хочет нечто современное, чтобы не выглядеть ретро. В будущем логотип планируется размещать везде: на сайте, использовать в полиграфии и в наружной рекламе. Заказчик ждет 1-2 варианта логотипа с презентацией на носителях, цвета у тебя уже есть – мятный и розовый. Ты можешь предложить любые оттенки этих цветов для использования их в лого.

**Позиционирование кафе** — семейное кафе, где каждый сможет попробовать натуральные сладости, приготовленные по домашним рецептам. Внимание к деталям от интерьера до тортов.

**Особенности кафе** — создание декоративных тортов по особым рецептурам на любой праздник, ланчбоксы для школьников, натуральные сладости.

**Целевая аудитория** — родители или просто женщины 35-40 лет, со средним достатком, которые заказывают красивые торты или просто не спеша пьют свежесваренный кофе на месте. Следят за своим здоровьем и здоровьем своих детей, стараются брать только натуральные продукты, обращают внимание на их составы. А также ЦА являются, и их дети 12+, которые забегают после или перед школой и берут с собой обеды или завтраки.

Создать одну или две версии шрифтового логотипа для кафе «Аист» и упаковать весь проект в презентацию для демонстрации потенциальному заказчику. Логотип можно показать на полиграфии: флаеры, бирки или наклейки для стаканчиков, вывески, плакаты для интерьера и т.д. Чем больше носителей ты выберешь, тем более нагляднее получатся твои идеи.

В презентации можешь разместить информацию о каждом проделанном шаге:
- Следует прописать задачу, исходя из ТЗ выше
- Показать референсы
- Описать одну или две идеи, рассказать почему подобраны тот или иной стиль / шрифт / цвет / композиционные решения для логотипа
- Показать один или два логотипа на мокапах (3-4 мокапа для логотипа будет достаточно, можно больше)
